# Database

The project uses PostgreSQL 17. SQLAlchemy connects through `DATABASE_URL`, and the schema dump is stored in `code/database/dashboard.sql`.

## Tables

### `public.user`

| Column | Type | Constraints / purpose |
| --- | --- | --- |
| `id` | integer | Primary key, generated by `user_id_seq`. |
| `username` | varchar(256) | Required and unique. |
| `email` | varchar(1024) | Required and unique. |
| `password_hash` | varchar(1024) | PBKDF2-SHA256 hash; never exposed by the API. |
| `first_name` | varchar(256) | Optional. |
| `last_name` | varchar(256) | Optional. |
| `created_at` | date | Defaults to the current date. |
| `updated_at` | date | Defaults to the current date and is updated by the service. |
| `status` | varchar(64) | Defaults to `active`. Inactive users cannot log in. |
| `is_admin` | boolean | Defaults to `false`. Controls admin endpoints. |
| `discord_id` | integer | Optional foreign key to `discord.primary_id`. |
| `steam_id` | integer | Optional foreign key to `steam.primary_id`. |
| `weather_id` | integer | Optional foreign key to `weather.primary_id`. |

### `public.discord`

| Column | Type | Constraints / purpose |
| --- | --- | --- |
| `primary_id` | integer | Internal primary key, generated by `discord_primary_id_seq`. |
| `id` | bigint | Discord's external ID; unique. |
| `username` | varchar(256) | Required. |
| `global_name` | varchar(256) | Required. |
| `email` | varchar(256) | Required. |
| `avatar` | varchar(256) | Required, may be empty. |

### `public.steam`

Currently contains only `primary_id`, an integer primary key generated by `steam_primary_id_seq`.

### `public.weather`

Currently contains only `primary_id`, an integer primary key generated by `weather_primary_id_seq`.

## Relationships

The `user` table stores optional service references:

```text
user.discord_id -> discord.primary_id
user.steam_id   -> steam.primary_id
user.weather_id -> weather.primary_id
```

Discord OAuth uses an upsert on the external Discord `id`, then stores the internal `primary_id` on the user.

## Local database

PostgreSQL is started by Docker Compose and exposed on port `5432`. The named volume `dashboard_dev_data` persists data between container restarts.

To recreate the schema from the dump, connect to the configured database and run:

```bash
psql "$DATABASE_URL" -f code/database/dashboard.sql
```

The dump contains sample user data. Do not use those credentials in a shared or production environment.
